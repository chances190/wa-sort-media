Back up your phone

Connect your phone with a USB cable, then pick a folder to copy files into.

📲 Set up your phone

  1. Connect your phone with a USB cable
  2. Tap the USB notification and choose File transfer
  3. Keep the phone unlocked while it works
Phone not showing up?
  • Unlock the screen — the phone won't appear while locked
  • Open the USB notification and choose File transfer, not "Charging only"
  • Try another cable or port (some cables only charge)
  • Tap Allow if the phone asks
  • Press ↻ to look again

Decrypt the database

Paste the 64-digit key from WhatsApp to unlock the backup.

🔐 About the key

WhatsApp → Settings → Chats → Chat backup → End-to-end encrypted backup. Without it, the database can't be decrypted.

Key length: 0/64 ✓ Looks good
Where do I find this key?

On your phone: WhatsApp → Settings → Chats → Chat backup → End-to-end encrypted backup. Choose Use a 64-digit encryption key. If you never set this up, enable it, back up again, and save the key.
